# JobPilot 求职驾驶舱

## 产品名称
JobPilot 求职驾驶舱

## 产品定位
JobPilot 是一款面向求职者的智能求职管理 Web 产品 MVP，核心目标是帮助用户把分散在不同平台、不同公司、不同岗位上的投递信息集中起来，用更系统化的方式管理投递进度、沉淀面试资料、识别能力缺口，并支持后续职业决策。

从产品定位上看，JobPilot 更接近“求职场景下的轻量 CRM + 决策看板 + 能力成长助手”，而不是传统招聘网站。

## 目标用户
- 校招求职者
- 实习求职者
- 社招求职者
- 需要同时管理多条投递流程的转岗用户
- 希望系统整理求职资料、面试反馈和职业路径信息的用户

## 用户痛点
- 投递记录分散在 Boss 直聘、猎聘、智联、前程无忧、牛客、官网、邮箱、内推群等多个入口，难以统一查看。
- 无法清晰追踪岗位所处阶段，例如已投递、筛选中、笔试、一面、二面、HR 面、Offer、已拒绝。
- 查看岗位 JD 时，缺少“我和这个岗位到底有多匹配”的直观判断依据。
- 公司信息、行业趋势、面经、视频讲解、学习资料分散在多个平台，求职准备成本高。
- 面试安排、联系人沟通、薪酬对比、职业路径规划缺少统一管理工具。

## 核心功能
- Dashboard 求职总览
  统一展示投递总量、面试进度、Offer 数量、匹配度、投递漏斗、行业分布、岗位类型分布、最近面试和待办提醒。
- 投递管理
  支持浏览、搜索、筛选、排序、新增、删除、更新岗位状态，并基于 localStorage 持久化数据。
- 岗位详情页
  展示岗位基础信息、JD、公司与行业信息、匹配度分析、面试资料、职业路径等内容。
- 模拟面试
  支持选择岗位与面试类型，生成模拟问题，并基于本地规则输出回答反馈。
- 技能提升
  自动统计高频技能、已掌握技能、缺失技能，并给出学习路径与资源建议。
- 面试日历
  展示面试安排、时间、轮次、形式、会议链接、提醒事项与准备材料。
- 联系人管理
  统一管理 HR、面试官、内推人、猎头等联系人信息及沟通记录。
- 薪酬与职业发展
  展示薪资范围、年薪估算、岗位级别、职业路径与未来发展建议。

## 页面说明

### 1. Dashboard 首页
用于展示整个求职过程的总览信息，是求职过程中的“决策看板”。

### 2. 投递管理
用于统一管理所有岗位投递记录，具备搜索、筛选、排序和状态维护能力，是项目中的核心管理页面。

### 3. 岗位详情
用于查看单个岗位的完整情报，包括 JD、匹配度、公司信息、面试资料和职业路径，是“岗位研究中心”。

### 4. 模拟面试
用于围绕目标岗位进行结构化问答练习，帮助用户在面试前提升表达质量。

### 5. 技能提升
用于从所有投递岗位中提炼高频技能，识别用户能力缺口，并输出学习资源与提升路径。

### 6. 面试日历
用于管理面试时间、轮次、会议链接和准备任务，降低多岗位并行时的时间混乱问题。

### 7. 联系人管理
用于集中沉淀 HR、面试官、内推人和猎头等外部联系人，方便后续跟进和沟通记录复用。

### 8. 薪酬与职业发展
用于对比不同岗位和城市的薪资区间，并从职业成长视角辅助用户做出更长期的判断。

## 当前 MVP 边界
- 当前版本为纯前端 MVP，不接真实后端服务。
- 当前版本不接真实 AI API，匹配分析、模拟面试反馈等能力基于本地规则生成。
- 当前版本不包含登录注册。
- 当前版本数据以 mockData 初始化，并通过 localStorage 保存用户新增、编辑、删除后的结果。
- 当前版本重点验证的是“求职管理中台”这一产品方向是否成立，以及核心信息架构是否顺畅。

## 后续可扩展方向
- 接入真实账号体系与云端同步，支持跨设备使用。
- 接入真实 AI 能力，用于 JD 匹配度分析、简历优化建议、模拟面试追问、岗位研究摘要等。
- 增加批量导入能力，例如支持从 Excel、Notion、CSV、招聘平台链接导入投递记录。
- 增加真实日历联动与通知提醒能力。
- 增加简历版本管理与岗位对照分析。
- 增加 Offer 对比与城市生活成本分析模块。
- 增加求职复盘、目标管理、学习计划和周报能力。

## 产品经理视角的项目价值
- 这个项目并不是“做一个页面集合”，而是围绕真实求职场景，完成了一次从用户痛点识别、信息架构设计、MVP 范围收敛到前端原型落地的完整产品实践。
- 项目体现了产品经理在复杂信息场景中的结构化能力：将投递、面试、联系人、技能、薪酬、职业路径等分散信息统一进一个产品体系。
- 项目展示了较强的 MVP 意识：优先验证高价值场景和核心闭环，而不是一次性做成复杂的全量系统。
- 项目适合作为作品集展示“从 0 到 1 定义产品”的过程，也适合在面试中展开讲述产品定位、用户研究、功能拆解、页面设计和后续路线规划。

## 项目说明
本项目当前更适合作为产品原型 / 作品集展示版本，而不是生产环境成品。它强调的是产品思考的完整性、页面信息组织能力以及前端可运行 Demo 的落地能力。
